ABOUT THE PROJECT

Diabetes Prediction System

A machine-learning project demonstrating the integration of predictive analytics with a Flask web application.

Project Overview

The Diabetes Prediction System is a machine-learning based web application designed to estimate diabetes risk from selected health parameters.

The application accepts patient information, applies the same preprocessing used during model development, and generates a prediction using the trained model.

Objective

The objective of this project is to demonstrate how machine learning can be integrated into a practical web application.

Technologies Used

Python

Programming and ML development.

Flask

Web application backend.

Scikit-learn

Machine learning and evaluation.

Pandas

Dataset processing and analysis.

NumPy

Numerical computation.

SQLite

Prediction history storage.

HTML & CSS

Frontend interface.

Joblib

Model serialization.

Input Parameters

The model accepts: Pregnancies, Glucose, Blood Pressure, Skin Thickness, Insulin, BMI, Diabetes Pedigree Function and Age.
