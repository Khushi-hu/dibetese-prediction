ABOUT THE PROJECT

Diabetes Prediction System

DiabetesAI is a machine-learning based web application developed as a mini project to demonstrate how healthcare data can be processed and analyzed using machine learning.

Objective

The objective is to develop a system that uses selected health parameters to generate a diabetes risk classification.

Machine Learning

The application uses a trained classification model along with preprocessing techniques such as imputation and feature scaling.

Web Application

Flask is used to connect the machine learning model with an interactive web interface.

Technologies

Python, Flask, NumPy, Pandas, Scikit-learn, HTML and CSS are used in the project.

Project Workflow

Dataset → Preprocessing → ML Model → Flask → Prediction
Educational Project

This system is intended for educational and demonstration purposes. It should not be used as a substitute for professional medical diagnosis.
